# 报销流程

## 适用范围

适用于差旅费、业务招待费、办公用品采购、通讯补贴等日常费用的报销申请。

## 报销类别与标准

- **差旅费**：交通、住宿、市内交通、餐饮补助，具体标准见《差旅政策》文档，需提前申请差旅审批单。
- **业务招待费**：单次超过 500 元需部门负责人审批，超过 2000 元需分管副总审批，须注明招待对象与事由。
- **办公用品**：单价 200 元以下可先采购后报销，200 元以上建议走采购申请流程，避免报销被打回。
- **通讯补贴**：按岗位等级每月定额发放，无需单独报销，随工资统一发放。

## 报销步骤

1. 登录财务系统「费用报销」模块，选择报销类别，填写费用明细。
2. 上传发票或电子发票 PDF，系统会自动 OCR 识别发票信息，请核对金额是否一致。
3. 关联对应的审批单（如差旅审批单、招待审批单），没有前置审批单的费用可能被驳回。
4. 提交后进入审批链：直属上级 -> 财务初审 -> 财务复核（大额费用需分管领导审批）。
5. 审批通过后，财务将在 5 个工作日内完成打款，打款结果可在系统「报销记录」中查询。

## 发票要求

- 必须为增值税普通发票或电子发票，抬头统一为公司全称，个人抬头发票无法报销。
- 餐饮发票需注明参与人数及事由，无法提供明细的，超过 300 元部分不予报销。
- 出租车/网约车发票需保留行程单或订单截图作为辅助材料。

## 常见问题

**Q: 发票丢失了怎么办？**
A: 可联系开票方补开发票或提供发票复印件加盖公章证明，同时提交情况说明，由财务酌情审核。

**Q: 报销多久能到账？**
A: 审批通过后一般 5 个工作日内到账，月末结账期间（每月最后 3 个工作日）可能延后至下月初处理。

**Q: 报销被驳回了怎么处理？**
A: 系统会注明驳回原因，按提示修改后重新提交即可，无需重新走审批流程。

如对报销政策有疑问，请联系财务部门（内部分机 8002，或飞书搜索"财务服务台"）。
