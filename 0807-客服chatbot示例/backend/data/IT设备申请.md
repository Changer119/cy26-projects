# IT 设备申请

## 适用范围

适用于笔记本电脑、显示器、耳机、键鼠等办公设备的新申请、更换、维修与归还。

## 设备申请类型

- **新员工入职领用**：入职当天由 IT 部门统一配发标准配置笔记本电脑及外设，无需单独申请。
- **设备升级/更换**：设备使用满 3 年，或岗位需要高配置（如算法、设计岗），可提交升级申请。
- **设备维修**：设备出现硬件故障（无法开机、屏幕损坏、电池老化等）可提交维修工单。
- **外设申领**：显示器、耳机、鼠标键盘等，每人限领一套，遗失或损坏需说明原因方可补领。

## 申请步骤

1. 登录 IT 服务台系统（IT Portal），选择对应的申请类型并填写设备用途说明。
2. 设备升级/更换类申请需部门负责人审批，审批通过后由 IT 统一采购或调拨库存设备。
3. 维修类工单提交后，IT 支持会在 1 个工作日内联系上门取件或远程排查。
4. 领用设备时需在系统中确认「资产领用单」，设备资产编号将绑定到员工工号。
5. 设备到货/维修完成后，系统会推送通知，员工需在 3 个工作日内到 IT 前台完成交接确认。

## 设备归还

- 离职、转岗或设备报废时，需将设备及配件（电源适配器、包等）一并归还至 IT 前台。
- 归还前请自行备份个人数据，IT 会对设备进行统一数据清除和重新装机，不承担数据备份责任。
- 未按时归还设备的，将从最终工资或押金中扣除设备残值。

## 常见问题

**Q: 电脑坏了但着急用怎么办？**
A: 可在维修工单中勾选「紧急」，IT 会优先处理，并视情况提供备用机应急使用（需在 IT 前台登记借用）。

**Q: 可以申请指定品牌/型号的设备吗？**
A: 标准配置统一采购，如有特殊工作需要（如需要 Mac 做 iOS 开发），需部门负责人书面说明理由并走特批流程。

**Q: 软件许可证（如 Office、设计软件）怎么申请？**
A: 在 IT Portal 的「软件申请」子模块提交，常用软件（Office、企业微信/飞书等）通常已预装，无需单独申请。

如对 IT 设备政策有疑问，请联系 IT 服务台（内部分机 8003，或飞书搜索"IT 服务台"）。
